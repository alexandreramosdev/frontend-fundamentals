# Frontend Fundamentals

Exercícios e anotações de fundamentos de front-end do curso de Engenharia de Software.

## Conteúdo

- `01-internet.md` — anotações sobre a internet.
- `01/` a `10/` — exercícios progressivos de HTML e CSS.
- `image.png` e `image-1.png` — imagens de apoio.

## Como visualizar

Abra o `index.html` de cada pasta no navegador. Para servir a pasta localmente:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Tecnologias

HTML5 e CSS3.
